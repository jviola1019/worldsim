Generated by `node tools/param-registry.mjs` from [`src/config/balance.ts`](../src/config/balance.ts); `tests/config/parameters.test.ts` fails if this file is stale or a parameter lacks an evidence class or a description. Do not edit by hand.

**Evidence classes**

| Class | Meaning | Count |
|---|---|---|
| **[E]** evidence-informed shape | The direction or shape follows published evidence (e.g. mortality schedules, demographic transition); magnitudes are rounded and illustrative | 13 |
| **[S]** stylized | Chosen for plausible, playable behaviour; not fitted to data | 90 |
| **[C]** calibrated | Tuned until a measured simulation outcome met a stated target; the record is named | 7 |
| **[T]** technical | An engine or planning setting, not a model assumption | 2 |

112 parameters in `BALANCE`. **No coefficient is claimed to be empirically validated against real-world data**; the simulation is a stylized model whose aggregate behaviour is checked by the experiments in [METHODS.md](METHODS.md). The mortality and fertility schedules outside `BALANCE` (`MORTALITY_PRE`, `MORTALITY_MODERN`, `FERTILITY_SHAPE`) are [E].
