# Round 10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** an honest nation count; Realistic as a grounded sandbox that starts empty and develops slowly; an Observer preset; a feed panel themed by its medium with one scroll; WCAG 2.2 AA checked with axe-core; and every game mode audited, then fixed or removed.

**Architecture:**
- Two new saved settings, `powerSet` and `pace`, each read through one function (`powerSetOf`, `paceMult`).
- Medium themes are CSS custom-property token sets chosen by a `data-medium` attribute on the sheet. A TS token table drives a contrast unit test.
- Accessibility runs as a separate e2e script that uses axe-core.
- The mode audit is a probe script plus promise tests.

**Tech Stack:** TypeScript 7, Preact 11, Vite 8, Vitest 5, Playwright 1.65 (Chromium and WebKit), axe-core (new, dev only).

**Spec:** `docs/superpowers/specs/2026-11-20-round10-design.md` (approved)

## Global Constraints

- **Determinism:** only `sim.rng` affects history. `pace === 'standard'` must leave every multiplier at exactly 1 and add no RNG draws. The four round-9 modernization outputs must be byte-identical, apart from the run time in the header line.
- **Old saves:** a missing `powerSet` means `observer ? 'none' : 'all'`. A missing `pace` means `'standard'`. Both new fields are validated on decode (unknown value means refuse the file).
- **CSP** stays `'self'`. axe-core runs only in an e2e context with `bypassCSP: true`.
- **Floors:** 12-px text, 44-px targets, Reduce motion honoured, 0 design-capture violations.
- **Contrast:** text ≥ 4.5:1, large text ≥ 3:1, controls and focus ≥ 3:1.
- **Slow targets** (placed band of 24 next to fresh water, 128², 5 seeds):
  - first village: median ≈ 100 years, every seed 40–250;
  - first settlement of 10,000: median ≈ 1,000 years, every seed 600–1,600;
  - no seed dies out before year 300.
- **Docs honesty:** say "WCAG 2.2 AA automated and manual checks passed in emulated Chromium and WebKit". Never "ADA compliant" or "certified".
- **Commits** end with the two attribution lines, and no model identifiers go into repository files.

## Review Focus

1. **An old Realistic (observer) save** must load with no powers, not with the grounded set. *(Task 2 test)*
2. **A disallowed power reached another way** (brush stroke continuation, undo, a stale tool selected before a preset change, the inspector's trait editor or missions) must be refused, not applied. *(Task 2 test)*
3. **An empty feed in a themed medium** must keep its empty-state text readable, and the sheet must still scroll. *(Task 5 contrast pair `muted`; Task 6 e2e)*
4. **Switching the feed filter to another nation's medium while scrolled down** must reset the scroll to the top, without keeping a stale theme. *(Task 6 e2e)*
5. **The HUD card at 320 px**, with a long world name and large counts ("12.3M people · 18 nations · 4 tribes"), must not overlap the speed controls or scroll sideways. *(Task 1 e2e)*
