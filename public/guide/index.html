The code map

Each circle is a folder of src/; its size is its number of lines. Lines show which folders use which. Select a folder to see its files and what each does. The simulation sits in the middle; rendering and ui only read it.

Select a folder.

The heartbeat: one simulated year

A year is 120 ticks (about 3 days each). Drag the slider or press play to watch what runs on each tick. Settlements take turns each month (by id), nations take turns each year, world-wide systems run on day 0.
